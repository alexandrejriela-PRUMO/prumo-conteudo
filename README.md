# prumo-conteudo

Artes publicadas nas redes do PRUMO Hub e o que a tarefa agendada usa para gerá-las.

- `INSTRUCOES.md`: como os posts são gerados, aprovados e publicados.
- `historico.md`: lista dos posts já publicados.
- `sistema/`: modelo das artes (render.py), logo e fontes (Poppins, licença OFL em `sistema/fontes/OFL.txt`).
- `posts/`: uma pasta por post publicado (post.json + imagens).

Este repositório é público porque o Instagram precisa buscar as imagens por link aberto.
Não coloque aqui nada que não vá ser publicado.
